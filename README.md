# Экскурсия в Самарский зоопарк

Сайт-презентация к уроку биологии для 8 класса.
Тема: «Зоология. Экология. Многообразие животных и их приспособленность к среде обитания».

Открыть сайт: https://fedik2005.github.io/samara-zoo-lesson/

Листать слайды: стрелки на клавиатуре, колёсико мыши или свайп. M - карта зоопарка, T - панель учителя, S - звук, F - полный экран.

Как вставить видео и аудио, рассказано в файле `Инструкция.txt`. Источники и авторы фотографий: `credits.html`.
